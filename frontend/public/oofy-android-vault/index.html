What it backs up

Nothing left behind

Most backup tools only grab the camera roll. OOFY Android Vault is built to catch everything, wherever an app decided to hide it.

Whole-storage search

Optionally scans every folder on the phone — not just Camera and Downloads — so nothing gets missed.

Photos, docs & video

Images, PDFs, Office files, screenshots and video, filtered by type or matched with your own custom extensions.

Contacts & messages

Exports contacts to a standard .vcf file and SMS history to .csv, alongside your media.

Mirrors your folders

Backed-up files land in the same folder layout as your phone, so the drive stays easy to browse.

Fast repeat backups

Already-copied files are skipped automatically — the second backup only moves what actually changed.

100% local

No sign-in, no cloud storage, no telemetry. Files travel over USB straight to the drive you pick.

Before you install

What you'll need

Operating system
Windows 10 or 11, 64-bit
Phone connection
A USB cable, with USB debugging enabled once on the phone (Settings → About phone → tap "Build number" 7 times → Developer options → USB debugging)
Android SDK Platform Tools
Required for the USB connection to work — OOFY Android Vault will tell you if it's missing and link you to it
Account or sign-in
None. There is no account, no cloud storage and nothing is sent anywhere.
